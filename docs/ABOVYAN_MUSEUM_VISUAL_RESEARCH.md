# Abovyan Museum Visual Research

Today the visual system is tuned for museum projection work at the Museum of the Abovyan.
Do not use the full personal name in screen copy; use "Abovyan Museum", "Museum of the Abovyan", or shorter room/collection language.

## Direction

- Treat the museum as archive, house, courtyard, room tone, stone, ink, manuscript, and public memory.
- Avoid club and flyer language from the previous event setup.
- Use quiet but high-contrast terminal matter: white blocks, blue/cyan shadows, magenta as a restrained signal color.
- Camera/photo input should become archival texture: cropped, thresholded, tinted, glitched like scanned paper or stone surface.
- Poster modes should read as museum wayfinding and live visual signage, not as an event flyer.

## Mode Notes

- `LIQUID` mode: archival liquid/chrome movement, like ink and light passing over paper.
- `POSTER` mode: museum poster/wayfinding system with room labels, metadata, arcs, and block artifacts.
- `SHARDS` and `SPLIT`: useful for fragmented archive, window, and manuscript textures.
